CI/CD Explanation

  1. Developer: Developer writes code and pushes it to GitHub.
  2. Jenkins: Jenkins automatically starts the CI pipeline.
  3. Build & Test: The application is built and tested.
  4. Docker: Jenkins creates a Docker image.
  5. AWS ECR: The Docker image is pushed to Amazon ECR.
  6. ArgoCD: ArgoCD follows GitOps and synchronizes the Kubernetes deployment.
  7. Kubernetes: The application is deployed to an EKS cluster.
  8. Monitoring: Prometheus and Grafana monitor the application and infrastructure.
